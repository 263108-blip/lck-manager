## 직접 플레이 확인 기록

현재 세션에서 itch 공개 페이지의 브라우저 렌더링과 내부 실행 환경을 직접 확인하지 못했습니다. 따라서 참고 게임 내부 화면은 "확인 못함"으로 분류하며 추측 확인으로 기록하지 않습니다.

## 2026 데이터 원칙

- 공식 발표와 계약 상태는 구분합니다.
- 보도 및 루머는 확인 상태로만 표시합니다.
- 2027 데이터와 2026 세이브 키를 혼합하지 않습니다.
- 날짜 및 나이는 기준 연도와 생년월일로 계산할 수 있는 구조를 우선합니다.
